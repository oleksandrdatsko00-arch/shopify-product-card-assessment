# Domaine Technical Assessment - Product Card

## Overview

A custom-built, headless-ready Shopify product card component based on the provided Figma specifications.

## Links

- **Live Prototype:** [https://domaine-technical-test-1.myshopify.com/collections/all] (Password: `gewfri`)
- **Repository:** [https://github.com/oleksandrdatsko00-arch/shopify-product-card-assessment]

## Tech Stack

- Shopify Liquid
- TailwindCSS
- Vanilla JavaScript (ES6)

## Features Included

- Markdown pricing and dynamic "On Sale" badge.
- Interactive variant swatches that dynamically update images and product links.
- Secondary image reveal on hover.
- Fully responsive design using utility-first CSS.
